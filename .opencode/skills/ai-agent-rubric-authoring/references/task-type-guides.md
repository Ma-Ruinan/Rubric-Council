# Task-type guides

## Objective extraction and frozen data

Recompute exact gold values from the real file. Record sheet/page/table/cell locators, units, formulas, row filters, missing-value conventions, and tolerances. Useful anchor patterns include exact financial-statement values plus derived ratios, or spreadsheet row/column counts plus independently verified missing/duplicate/anomaly counts. Do not copy a prior rubric's numbers without recomputation.

## Data cleaning and analysis

Profile physical blanks versus textual missing markers, exact duplicate rows versus duplicate business keys, type/range anomalies, formula inconsistencies, and category variants. Permit different defensible cleaning strategies; judge rule consistency, information preservation, traceability, and whether pivots/charts recompute from cleaned data. Do not prescribe one final row count unless the task determines it.

## Document, slide, and format transformation

Extract source facts first, then identify what the requested artifact must preserve and what transformation the prompt explicitly requires. For slides, page count, editable structure, and a requested process diagram may be objective; preferred colors, layouts, or extra charts are not unless specified. Inspect native structure and rendering.

## Code diagnosis and software engineering

Freeze repository, tag/commit, runtime, and dependency versions. Trace the relevant call path, identify the causal mechanism, define semantically valid fixes, and derive tests that distinguish the bug from adjacent behavior. A later official patch may corroborate but must not replace analysis of the named version. Never treat test design as proof that tests ran.

## Open research and browsing

Define cutoff, source hierarchy, mandatory topic from the prompt, and conclusion-changing claims. Put fixed facts, explicit coverage, source quality, and cutoff compliance in the objective-verifiable layer. Put viewpoint, synthesis structure, prioritization, recommendation, and conclusion in the allowed-variation layer, with minimum support and invalid boundaries. Test at least one pair of contrasting defensible paths. Alternative sources and conclusions remain valid when equally supported. Do not transform one researched outline into compulsory regions, companies, or fact counts unless the prompt requires them. Distinguish event date, publication date, prediction, order, production, shipment, deployment, and later commentary.

## Multi-agent and workflow tasks

Judge separable task definitions, distinguishable work products, execution evidence, source attribution, and synthesis. Role labels alone do not prove independent work. Do not require a particular division of labor when the prompt permits equivalent decompositions.

## Security and system tasks

Freeze version and environment. Require evidence-to-finding linkage, severity rationale, remediation specificity, and safety boundaries. Separate confirmed impact from hypotheses and do not reward destructive proof.

## Mixed tasks

Use the dominant source of truth for each criterion. A task may combine objective anchors, open analysis, artifact quality, and process evidence; do not apply one task type's thresholds to another component.
